# The Monday rental review

Run `npm run rental -- attention --json`, `npm run rental -- utilisation --json` and `npm run rental -- balances --json`. Read booking details for exceptions. Write decisions in this order: late vehicles, unsafe or unprepared fleet, damage and notice deadlines, balances by currency, then unused capacity. Name the actual records and the owner who needs to act if supplied. Save a draft to drafts/weekly-review.md. Never send it.
