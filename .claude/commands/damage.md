# Decide the damage register

Read CLAUDE.md. Read booking and evidence first. Use damage-add to record a finding and damage-decide to charge or waive it with a reason. A charge is a record, never a card debit.

Run `npm run rental -- damage`. Replace angle-bracket values with the operator's facts. Add `--json` for structured output. Report from the fresh result and identify missing facts.
