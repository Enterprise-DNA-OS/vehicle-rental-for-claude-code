# Add a view

Read views.json and the existing SQL views. Translate the requested question into a SELECT query, verify against current records, then add a section or a new named page in views.json. Add a migration if a reusable SQL view is needed. Render with npm run view and inspect the HTML. Keep currency groups separate, label estimates, escape all record text through the shared renderer and include only the personal details required for the job. No forms, front end or write controls.
